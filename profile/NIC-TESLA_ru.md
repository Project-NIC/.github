# NIC-Tesla — приёмник молний / TGF (сферикс)

Назван в честь **Николы Теслы** (высокое напряжение / катушка Теслы). Самодельный
**сфериксный приёмник** — **четыре ферритовых стержня** на раме в форме усечённой
пирамиды + дифференциальный front-end **THS4551** + АЦП **ADS127L14** — который
детектирует молнии **на краю** (edge-AI классификация) и отправляет крошечную
**фиксированную запись события**, а не сырые осциллограммы.

Tesla — это **одна единица NodeBus, тип 7, на одной плате**: аналоговый фронт и
**STM32H523, на котором работает её DSP**, делят одну печатную плату в одной коробке IP68
на антенной раме. Единственный разъём — **сокет Galvani**.

Поскольку все узлы делят одни сетевые часы — **доставленная одна микросекунда** — каждый
разряд получает метку времени для сетевой мультилатерации (TOA по разнесённым станциям), а
гамма-вспышку грозы (**TGF**) можно сопоставить с радиационными платами (**Quark** /
**Photon**).

Проект на бумаге: детектирование — твёрдая часть; локализация требует широкой сети.
